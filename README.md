# 🚀 Cosmic Rescue: Dash & Save (Juego 2D)

Juego 2D web desarrollado con HTML, CSS y JavaScript, optimizado para dispositivos móviles y computadoras.

---

## 📋 Documentación por Fases

### 🔹 Fase 1: Estructura inicial y configuración
- Creación de la estructura base del proyecto (`index.html`, `style.css`, `script.js`, `README.md`).
- Creación de la carpeta `evidencias/` para guardar capturas del proceso.
- Inicialización y sincronización del repositorio con GitHub.

### 🔹 Fase 2: Maquetación HTML y Estilos Responsive
- Creación de la estructura semántica en `index.html` con panel de estado (HUD), área del Canvas y botones táctiles.
- Implementación de estilos CSS en `style.css` adaptados para pantallas móviles.

### 🔹 Fase 3: Mecánicas del Jugador y Controles Táctiles / Teclado
- Programación del bucle principal del juego (`gameLoop`) e inicialización del canvas responsivo en `script.js`.
- Configuración de eventos para teclado (flechas y teclas A/D) y eventos táctiles (`touchstart` / `touchend`) para interacción en pantallas de celular.
